# 已确认的技术与路线决策

- 沿用用户静态初版和 Leaflet 1.9.4。保留原 ZIP，独立子目录迭代，GitHub Pages 发布源为 `main` 根目录。候选及许可证见 [开源选型](OPEN_SOURCE_RESEARCH.md)。
- 用本地原创 SVG 与 Leaflet CRS.Simple 提供可拖动缩放的示意图。图内坐标是绘图单位，虚线表达景点顺序。来源可核查的 POI、区域示意、待核实无标记分开呈现。
- 高德通过 HTTPS 地点页和 URI 关键词检索提供导航入口。本站无需高德密钥、远程瓦片、登录或定位授权。
- 舒适拍照版和精简版是可编辑建议。舒适版优先保留奥海西侧银杏与仰山西坡。精简版优先保留和合牌坊、中轴银杏和奥海西侧银杏，视现场情况决定仰山。叠水花台、夕拾台、生态廊道留在审计中的候选名单。
- 打卡保存在浏览器本地，路线切换保留打卡。
