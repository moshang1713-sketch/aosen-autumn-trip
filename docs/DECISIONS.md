# 已确认的技术与路线决策

- 在原仓库和原 GitHub Pages URL 做增量升级。沿用静态 HTML/CSS/JS 和 BSD-2-Clause Leaflet 1.9.4。升级前可回滚的主分支提交是 `620c127`。
- 本轮采用 OSM WGS84 地理数据、FOSSGIS 步行几何快照和高德外链。高德 JS API 方案需单独授权及安全代理。来源、坐标系、设施差异及配额见 [地图技术决策](MAP_TECH_DECISION.md) 和 [地图数据审计](MAP_DATA_AUDIT.md)。
- 13:00 唯一集合点为奥林匹克公园站 G 东北口。两套建议计划暂以森林公园南门站 B 口返程。生态廊道、叠水花台、夕拾台不加入建议行程；活动日期、结束时刻和统一返程由组织者确认。
- 站内标记与高德导航使用同一目标的各自坐标系。以步道参考点表示区域，无法取得的路段留空。行程时间包括步行估算、活动和余量。
- 打卡继续保存在原浏览器存储键。实景照片按作者和许可逐张核对，暂缺照片的点明确显示待补充。
